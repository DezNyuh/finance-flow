# 💸 FinanceFlow

FinanceFlow is a personal Python project created to automate repetitive financial tasks.

The main goal is to register expenses quickly through Python and automatically fill them into the "Minhas Finanças" desktop application using PyAutoGUI.

This project was created to solve a real personal problem while improving my Python skills.

---

## Features

- Add expenses from the terminal
- Store data in JSON
- Desktop automation using PyAutoGUI

## Technologies

- Python

- PyAutoGUI
